## Optional Step: Paraphrase Soal (Buat Variasi Narasi/Skenario)

```bash
# Gunakan skill `exam-question-paraphraser`

## Folder Input

`@test`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file dengan ekstensi `*.md` yang ada di dalam subfolder `ori/` pada Folder Input (hasil pecahan dari `markdown-question-splitter`).
3. Buat folder `phraser/` di dalam Folder Input jika belum ada.
4. Untuk setiap file `.md` yang ditemukan (contoh: `test/ori/01_q01.md`), buat variasi narasi/skenario soal menggunakan skill **`exam-question-paraphraser`**.
5. Selama proses parafrase, terapkan aturan berikut:
   * **Variasi Entitas/Skenario:** Ubah subjek (contoh: "Ibu" → "Ayah"), barang/objek (contoh: "apel" → "roti"), dan latar tempat tanpa mengubah logika soal.
   * **Bahasa Ramah Anak:** Gunakan kalimat Bahasa Indonesia yang sederhana, komunikatif, ramah, dan mudah dipahami oleh anak-anak/pelajar sekolah. Hindari istilah formal/kaku yang membingungkan.
   * **Struktur Kalimat:** Ubah susunan kalimat atau bentuk aktif/pasif secara alami.
   * **Invarian (PANTANGAN):** DILARANG mengubah rumus matematika, angka perhitungan, parameter fisika/kimia, dan nilai kunci jawaban yang benar.
   * **Update Opsi Jawaban:** Sesuaikan kata-kata pada pilihan jawaban `(a)`, `(b)`, `(c)`, dst. agar tetap cocok dengan variasi baru.
   * **Update Path Gambar:** Jika ada referensi gambar relatif, pastikan path tetap menunjuk ke lokasi gambar yang benar (menggunakan prefix `../` karena folder `phraser/` berada di kedalaman yang sama dengan `ori/`).
6. Simpan file hasil parafrase ke dalam subfolder **`phraser/`** dengan **nama file yang persis sama** dengan file input. Contoh:
   * `ori/01_q01.md` → `phraser/01_q01.md`
   * `ori/01_q02.md` → `phraser/01_q02.md`
7. Ulangi proses hingga seluruh file `.md` di `ori/` selesai diparafrase dan tersimpan di `phraser/`.
8. Tampilkan ringkasan hasil berupa:
   * jumlah file `.md` yang berhasil diparafrase;
   * lokasi folder output (`phraser/`);
   * daftar perubahan entitas utama yang dilakukan.
```

## Contoh Penggunaan Per File (Opsional)

```bash
# Gunakan skill `exam-question-paraphraser`

## File Input

`@test/ori/01_q01.md`

## Instruksi

1. Gunakan **File Input** sebagai sumber soal.
2. Buat variasi narasi dan subjek pada file `@test/ori/01_q01.md` menggunakan skill **`exam-question-paraphraser`**.
3. Pastikan angka perhitungan dan kunci jawaban tetap sama.
4. Simpan hasil parafrase ke `test/phraser/01_q01.md`.
```
