## Step 1: Split soal (pecah file multi-soal & grup per N soal)

```bash
# Gunakan skill `markdown-question-splitter` (termasuk pre-processing `text-input-fixer`)

## Folder Input

`@.` # Atau tag folder spesifik seperti `@mma_snbt_2025` atau `@utbk`

## Parameter Pengelompokan (Group Size)

`20` # Ubah nilai ini jika ingin jumlah soal per folder yang berbeda (contoh: 30, 50, dst.)

## Informasi Struktur Folder

Folder Input (contoh: `utbk/`) memiliki struktur:
- `md/` : Berisi file-file `.md` sumber (contoh: `page_01.md`, `page_02.md`, dst.) dan opsional folder `md/imgs/` berisi gambar.
- `ori/`: Folder tempat hasil pemecahan soal disimpan dalam bentuk subfolder grup berdasarkan **Parameter Pengelompokan**.

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file `.md` yang ada di dalam subfolder `md/` pada Folder Input. Urutkan file berdasarkan penamaan.
3. Sebelum memecah soal, jalankan pre-processing menggunakan skill **`text-input-fixer`** untuk membersihkan teks mentah (perbaikan typo/EYD, mojibake/encoding, artefak OCR, format penomoran/opsi, dan perbaikan syntax LaTeX).
4. Pecah seluruh soal secara berurutan menggunakan skill **`markdown-question-splitter`** dengan penomoran global berurut (Soal 1, 2, 3, dst.).
5. **Pengelompokan per N Soal (Folder Grouping):**
   * Kelompokkan file hasil pecahan ke dalam subfolder di dalam `ori/` sesuai nilai **Parameter Pengelompokan** (misal N = 20 atau N = 30):
     - Jika N = 20: `ori/001-020/`, `ori/021-040/`, `ori/041-060/`, dst.
     - Jika N = 30: `ori/001-030/`, `ori/031-060/`, `ori/061-090/`, dst.
6. **Penanganan Gambar (Folder `imgs` per Grup):**
   * Jika suatu soal memuat gambar (contoh: `![chart](imgs/chart.png)` atau `<img src="imgs/chart.png">`):
     - Buat folder `imgs/` di dalam grup folder terkait (contoh: `ori/001-020/imgs/` atau `ori/001-030/imgs/`).
     - Salin file gambar yang dirujuk dari `md/imgs/` ke folder `imgs/` grup tersebut (`ori/001-020/imgs/chart.png` atau `001-020/imgs/chart.png`).
     - Pastikan path gambar di dalam file markdown soal (yang disimpan di dalam subfolder `ori/`) menunjuk secara relatif ke `../imgs/<nama_gambar>`.
7. **Aturan Tambahan:**
   * **Mode Single Agent:** Kerjakan seluruh proses secara mandiri menggunakan single agent. DILARANG memanggil/membuat subagent, delegate worker, atau tugas sub-task paralel.
   * **Wacana/Narasi Bersama:** Jika terdapat teks cerita/bacaan untuk beberapa soal berurutan, salin dan sisipkan wacana tersebut di bagian atas setiap file soal terkait.
   * **Penamaan File Soal:** Gunakan format `<no_soal_global>_q<no_soal>.md` atau `<ID_file>_q<no_soal>.md` (contoh: `001_q01.md`, `002_q02.md`, dst. di dalam grup foldernya).
8. Ulangi proses hingga seluruh file `.md` sumber selesai dipecah dan dikelompokkan.
9. Jangan membuat script untuk proses ini. Baca semua file secara manual untuk memastikan seluruh proses berjalan dengan benar.
10. Simpan report dalam format file markdown (`report.md`) di **Folder Input**. Laporan harus memuat rincian file sumber yang diproses dan rincian folder grup. Contoh hasilnya seperti berikut:
    # Detail Pemecahan dan Pengelompokan Soal

    ## 1. Rincian File Sumber (`md/`)
    | No | File Sumber (`md/`) | Range Soal | Jumlah Soal | Target Folder Grup |
    |---|---|---|---|---|
    | 1 | page_01.md | Soal 1 - 5 | 5 | ori/001-020 |
    | 2 | page_02.md | Soal 6 - 15 | 10 | ori/001-020 |
    | 3 | page_03.md | Soal 16 - 25 | 10 | ori/001-020, ori/021-040 |
    | 4 | page_04.md | Soal 26 - 44 | 19 | ori/021-040, ori/041-060 |

    ## 2. Rincian Folder Grup (`ori/`)
    | No | Group Folder | Range Soal | Total Soal | Folder Imgs |
    |---|---|---|---|---|
    | 1 | ori/001-020 | Soal 1 - 20 | 20 | Ada |
    | 2 | ori/021-040 | Soal 21 - 40 | 20 | Ada |
    | 3 | ori/041-060 | Soal 41 - 44 | 4 | Tidak Ada |
```

## Step 1: Split Questions (Multi-question file splitting & customizable N-question grouping) — English Version

```bash
# Use skill `markdown-question-splitter` (including pre-processing `text-input-fixer`)

## Input Folder

`@.` # Or tag a specific folder like `@mma_snbt_2025` or `@utbk`

## Group Size Parameter

`20` # Change this value to adjust the number of questions per folder (e.g., 30, 50, etc.)

## Folder Structure Information

The Input Folder (e.g., `utbk/`) has the following structure:
- `md/` : Contains source `.md` files (e.g., `page_01.md`, `page_02.md`, etc.) and an optional `md/imgs/` folder for images.
- `ori/`: Destination folder where split question files are saved into group subfolders based on the **Group Size Parameter**.

## Instructions

1. Use **Input Folder** as the working directory.
2. Read all `.md` files located inside the `md/` subfolder of the Input Folder. Sort files by filename.
3. Before splitting, execute pre-processing using the **`text-input-fixer`** skill to clean raw text (fix typos/grammar, mojibake/encoding, OCR artifacts, option/numbering formatting, and LaTeX syntax errors).
4. Split all questions sequentially using the **`markdown-question-splitter`** skill with global sequential numbering (Question 1, 2, 3, etc.).
5. **Grouping per N Questions (Folder Grouping):**
   * Group the split question files into range subfolders inside `ori/` matching the **Group Size Parameter** (e.g. N = 20 or N = 30):
     - If N = 20: `ori/001-020/`, `ori/021-040/`, `ori/041-060/`, etc.
     - If N = 30: `ori/001-030/`, `ori/031-060/`, `ori/061-090/`, etc.
6. **Image Handling (Per-Group `imgs` Folder):**
   * If a question contains an image reference (e.g., `![chart](imgs/chart.png)` or `<img src="imgs/chart.png">`):
     - Create an `imgs/` folder inside the respective group folder (e.g., `ori/001-020/imgs/` or `ori/001-030/imgs/`).
     - Copy the referenced image from `md/imgs/` into that group's `imgs/` folder (`ori/001-020/imgs/chart.png` or `001-020/imgs/chart.png`).
     - Ensure the image relative path inside the question markdown (stored inside the `ori/` subfolder) points to `../imgs/<image_name>`.
7. **Additional Rules:**
   * **Single Agent Mode:** Execute the entire process directly using a single agent. DO NOT spawn subagents, delegate workers, or parallel background sub-tasks.
   * **Shared Reading Passages:** If a reading passage or context story applies to multiple consecutive questions, copy and prepend the passage text to the top of each associated question file.
   * **File Naming Convention:** Use format `<global_q_num>_q<q_num>.md` or `<file_ID>_q<q_num>.md` (e.g., `001_q01.md`, `002_q02.md`, etc. inside its group folder).
8. Repeat the process until all source `.md` files are split and grouped.
9. Do not create a script for this process. Read all files manually to ensure the entire workflow executes accurately.
10. Save the report in markdown format (`report.md`) in the **Input Folder**. The report must include details of processed source files and group folders. Example report output:
    # Question Splitting and Grouping Summary

    ## 1. Processed Source Files (`md/`)
    | No | Source File (`md/`) | Question Range | Questions Extracted | Target Group Folders |
    |---|---|---|---|---|
    | 1 | page_01.md | Questions 1 - 5 | 5 | ori/001-020 |
    | 2 | page_02.md | Questions 6 - 15 | 10 | ori/001-020 |
    | 3 | page_03.md | Questions 16 - 25 | 10 | ori/001-020, ori/021-040 |
    | 4 | page_04.md | Questions 26 - 44 | 19 | ori/021-040, ori/041-060 |

    ## 2. Group Folders Summary (`ori/`)
    | No | Group Folder | Question Range | Total Questions | Imgs Folder |
    |---|---|---|---|---|
    | 1 | ori/001-020 | Question 1 - 20 | 20 | Yes |
    | 2 | ori/021-040 | Question 21 - 40 | 20 | Yes |
    | 3 | ori/041-060 | Question 41 - 44 | 4 | No |
```
