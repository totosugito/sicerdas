## Step 1: Split soal (pecah file multi-soal)

```bash
# Gunakan skill `markdown-question-splitter` (termasuk pre-processing `text-input-fixer`)

## Folder Input

`@test`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file dengan ekstensi `*.md` yang ada di dalam Folder Input (kecuali file di dalam subfolder `ori/` dan `exam/`).
3. Sebelum memecah soal, jalankan pre-processing menggunakan skill **`text-input-fixer`** untuk membersihkan teks mentah (perbaikan typo/EYD, mojibake/encoding, artefak OCR, format penomoran/opsi, dan perbaikan syntax LaTeX).
4. Untuk setiap file `.md` yang telah dibersihkan (contoh: `test/page_01.md`), pecah menjadi file-file kecil yang masing-masing berisi **satu soal** menggunakan skill **`markdown-question-splitter`**.
5. Selama proses pemecahan, terapkan aturan berikut:
   * **Wacana/Narasi Bersama:** Jika terdapat teks cerita/bacaan untuk beberapa soal berurutan, salin dan sisipkan wacana tersebut di bagian atas setiap file soal terkait.
   * **Update Path Gambar:** Ubah semua path gambar relatif dengan menambahkan prefix `../` (contoh: `imgs/chart.jpg` → `../imgs/chart.jpg`) karena file output berada di subfolder `ori/`.
   * **Penamaan File:** Gunakan format `<ID_file>_q<no_soal>.md` (contoh: `page_01.md` → `ori/01_q01.md`, `ori/01_q02.md`, dst.).
6. Simpan seluruh file pecahan secara otomatis ke dalam subfolder `ori/` di dalam Folder Input.
7. Ulangi proses hingga seluruh file `.md` di Folder Input selesai dipecah.
8. Setelah semua file selesai dipecah, tampilkan ringkasan singkat berupa:
   * jumlah file `.md` sumber yang diproses dan dibersihkan;
   * total soal yang berhasil diekstrak;
   * lokasi folder tempat file-file pecahan disimpan (`ori/`).
9. Jangan membuat script untuk proses ini. baca semua file secara manual untuk memastikan seluruh proses berjalan dengan benar
```

## Contoh Penggunaan Per File (Opsional)

```bash
# Gunakan skill `markdown-question-splitter`

## File Input

`@test/page_01.md`

## Instruksi

1. Gunakan **File Input** sebagai sumber soal.
2. Bersihkan file mentah `@test/page_01.md` menggunakan skill **`text-input-fixer`**, kemudian pecah menjadi file-file tunggal menggunakan skill **`markdown-question-splitter`**.
3. Simpan hasil pecahan ke folder `test/ori/` dengan format nama `01_q01.md`, `01_q02.md`, dst.
4. Pastikan path relatif gambar dan wacana bersama diproses dengan benar.
```
