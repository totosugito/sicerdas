## Generate JSON (proses per soal)

### Versi Bahasa Indonesia

```bash
# Gunakan skill `exam-question-generator`

## Folder Input

`@013`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file dengan ekstensi `*.md` yang ada di dalam subfolder `phraser/` (jika proses parafrase dijalankan) atau subfolder `ori/` pada Folder Input. Setiap file berisi **satu soal**.
3. Jika soal memiliki gambar (misal JPG/PNG), cari file .svg dengan nama yang sama di direktori tersebut. Jika .svg ditemukan, proses soal tersebut. Jika .svg tidak ada, baru abaikan/skip.
4. Buat folder `exam/` di dalam Folder Input jika belum ada. Usahakan semua proses dilakukan secara manual (tanpa membuat script) jika memungkinkan.
5. Proses setiap soal menggunakan **skill `exam-question-generator`**. Pastikan output format sesuai dengan instruksi dan skema yang dijelaskan pada skill.
6. Untuk setiap soal:
   * Hasilkan satu file JSON lengkap sesuai format output dari skill `exam-question-generator`.
   * JSON harus memuat seluruh informasi yang tersedia, termasuk metadata (`type`, `difficulty`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`, `tags`), `content`, `options`, `solutions`, dan `variableFormulas`.
   * **Parameterisasi Solusi:** Gunakan placeholder variabel (seperti `{{x}}`, `{{answer}}`) pada teks dan persamaan dalam `solutions.content` (bukan angka ter-evaluasi secara hardcode) agar langkah pembahasan dapat ter-update secara dinamis di semua variasi angka.
   * Wajib menyertakan solusi konseptual (`solutionType: "general"`). Sertakan trik cepat (`solutionType: "fast_method"`) jika terdapat rumus praktis/trik hitung cepat.
   * Pastikan format JSON sesuai dengan format `output-sample.json` di skill examples.
7. Setiap file JSON hanya boleh berisi **satu pertanyaan** (berupa JSON object tunggal, bukan array).
8. Nama file JSON output **sama dengan nama file input `.md`** (ganti ekstensi saja). Contoh:
   * `phraser/01_q01.md` (atau `ori/01_q01.md`) → `exam/01_q01.json`
   * `phraser/01_q02.md` (atau `ori/01_q02.md`) → `exam/01_q02.json`
   * `phraser/02_q01.md` (atau `ori/02_q01.md`) → `exam/02_q01.json`
9. Simpan seluruh file JSON ke dalam folder `exam/`.
10. Jika file tujuan sudah ada, timpa (overwrite) file tersebut.
11. Ulangi proses hingga seluruh soal pada seluruh file Markdown di `phraser/` atau `ori/` selesai diproses.
12. Jalankan skrip validasi offline untuk memastikan seluruh file JSON yang dihasilkan valid secara skema, layout opsi, dan formula:
    ```bash
    python3 .agents/skills/exam-question-generator/scripts/validate_questions.py <Folder Input>/exam/
    ```
13. Setelah semua soal selesai diproses dan divalidasi, tampilkan ringkasan yang berisi dalam bentuk file log format markdown yang disimpan di folder "Folder Input" dengan nama `summary.md`:
    * jumlah file Markdown yang diproses;
    * jumlah soal yang berhasil dikonversi;
    * jumlah file JSON yang dibuat;
    * status hasil validasi `validate_questions.py`;
    * daftar soal yang gagal diproses (jika ada) beserta penyebabnya.
```

### English Version

```bash
# Use skill `exam-question-generator`

## Input Folder

`@013`

## Instructions

1. Use **Input Folder** as the working directory.
2. Read all files with `*.md` extension inside the `phraser/` subfolder (if the paraphrasing process was run) or the `ori/` subfolder in the Input Folder. Each file contains **one question**.
3. If a question has an image (e.g. JPG/PNG), search for an .svg file with the same name in that directory. If the .svg is found, process that question. If the .svg is missing, ignore/skip it.
4. Create an `exam/` folder inside the Input Folder if it does not exist yet. Try to perform all processes manually (without creating scripts) if possible.
5. Process each question using the **`exam-question-generator` skill**. Ensure the output format matches the schema and guidelines described in the skill.
6. For each question:
   * Generate one complete JSON file according to the output format of the `exam-question-generator` skill.
   * JSON must contain all available information, including metadata (`type`, `difficulty`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`, `tags`), `content`, `options`, `solutions`, and `variableFormulas`.
   * **Solution Parameterization:** Use variable placeholders (such as `{{x}}`, `{{answer}}`) in `solutions.content` text and equations (do NOT hardcode evaluated numbers) so solution steps update dynamically across all numerical variations.
   * Include mandatory conceptual solution (`solutionType: "general"`). Include fast method (`solutionType: "fast_method"`) whenever a calculation shortcut/trick exists.
   * Ensure the JSON format matches the `output-sample.json` format in skill examples.
7. Each JSON file must contain only **one question** (as a single JSON object, not an array).
8. The output JSON filename **must match the input `.md` filename** (change extension only). Example:
   * `phraser/01_q01.md` (or `ori/01_q01.md`) → `exam/01_q01.json`
   * `phraser/01_q02.md` (or `ori/01_q02.md`) → `exam/02_q01.json`
   * `phraser/02_q01.md` (or `ori/02_q01.md`) → `exam/02_q01.json`
9. Save all JSON files into the `exam/` folder.
10. If the destination file already exists, overwrite it.
11. Repeat the process until all questions in all Markdown files in `phraser/` or `ori/` are processed.
12. Run the offline validator script to verify schema compliance, option layout, and mathjs formulas for all generated JSON files:
    ```bash
    python3 .agents/skills/exam-question-generator/scripts/validate_questions.py <Input Folder>/exam/
    ```
13. After all questions are processed and validated, generate a summary in the form of a markdown log file saved in the "Input Folder" named `summary.md`:
    * number of Markdown files processed;
    * number of questions successfully converted;
    * number of JSON files created;
    * validation status results from `validate_questions.py`;
    * list of questions that failed to process (if any) along with the reasons.
```
