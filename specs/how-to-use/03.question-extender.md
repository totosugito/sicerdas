## Step 3: Tambah Soal (Extender)

```bash
# Gunakan skill `exam-question-extender`

## Folder Input

`@test`

## Jumlah Target Soal per Folder

`20`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Periksa file `report.md` di dalam **Folder Input** untuk mengidentifikasi folder-folder yang memiliki jumlah **Total Soal** kurang dari **Jumlah Target Soal per Folder** (contoh: target 20 soal).
3. Untuk setiap folder yang membutuhkan tambahan soal:
   * Baca seluruh file soal eksisting di dalam subfolder `ori/` untuk menganalisis bab/topik, tingkat kesulitan, variasi rumus, dan distribusi sub-topik.
   * Buat soal-soal baru yang relevan dengan topik tersebut untuk menutupi kekurangan hingga mencapai **Jumlah Target Soal per Folder**.
   * Format soal baru harus mengikuti standar Markdown dengan LaTeX `$$...$$` dan opsi pilihan ganda `(a)` hingga `(e)`.
4. Simpan masing-masing soal baru langsung ke dalam subfolder `ori/` pada folder target yang bersangkutan, menggunakan penamaan `new_q01.md`, `new_q02.md`, `new_q03.md`, dst. Jangan menimpa file soal eksisting (`01_q01.md`, dst.).
5. Setelah pembuatan soal baru selesai, perbarui file `report.md` di **Folder Input** dengan memperbarui kolom `Soal Baru` dan `Total Soal` untuk setiap folder yang ditambahkan soalnya.
6. Tampilkan ringkasan singkat berupa daftar folder yang ditambahkan soalnya, jumlah soal baru yang dibuat per folder, dan total akhir soal.
```

## Contoh Penggunaan per Folder Spesifik (Opsional)

```bash
# Gunakan skill `exam-question-extender`

## Folder Target

`@test/024`

## Jumlah Soal Baru yang Dibuat

`10`

## Instruksi

1. Baca seluruh file soal eksisting di subfolder `ori/` pada **Folder Target**.
2. Analisis bab/topik (*PERSAMAAN KUADRAT*), tingkat kesulitan, dan distribusi sub-topik.
3. Buat **Jumlah Soal Baru yang Dibuat** (10 soal baru) yang relevan dan berkualitas tinggi.
4. Simpan masing-masing soal baru ke subfolder `ori/` di dalam **Folder Target** dengan penamaan `new_q01.md` hingga `new_q10.md`.
5. Perbarui file `report.md` di direktori induk dari **Folder Target** (kolom `Soal Baru` dan `Total Soal`) sesuai hasil penambahan soal.
```
