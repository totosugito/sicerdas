## Generate Solution Markdown (Tahap 1: Pembahasan & Parameterisasi)

### Versi Bahasa Indonesia

```bash
# Gunakan skill `exam-solution-generator`

## Folder Input

`@013`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file dengan ekstensi `*.md` yang ada di dalam subfolder `phraser/` (jika proses parafrase dijalankan) atau subfolder `ori/` pada Folder Input. Setiap file berisi **satu soal**.
3. Jika soal memiliki gambar (misal JPG/PNG), cari file `.svg` dengan nama yang sama di direktori tersebut. Jika `.svg` ditemukan, periksa file gambar tersebut untuk mengekstrak informasi/angka yang tersembunyi pada diagram (seperti sudut, nilai gaya, kecepatan awal). Jika `.svg` tidak ada, baru abaikan/skip.
4. Buat folder `solution/` di dalam Folder Input jika belum ada.
5. Proses setiap soal menggunakan **skill `exam-solution-generator`**.
6. Untuk setiap soal:
   * Hasilkan satu file Markdown lengkap berisi YAML frontmatter dan bagian pembahasan terstruktur.
   * **YAML Frontmatter:** Memuat metadata (`type`, `difficulty`, `tags`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`) serta `variableFormulas` (minimal 5 set variasi angka dan daftar formula perhitungan intermediate dengan sintaks `mathjs` murni).
   * **Struktur Pembahasan:**
     - `## Soal`: Teks soal beserta formula TeX (`$...$` dan `$$...$$`) dan referensi gambar `![caption](file.png)`.
     - `## Opsi`: Daftar pilihan jawaban dengan penanda `- [x]` untuk jawaban benar dan `- [ ]` untuk jawaban salah.
     - `## Alasan`: Teks alasan (khusus untuk tipe `statement_reasoning`).
     - `## Pembahasan: Cara Konseptual`: Wajib memuat **Diketahui:** (ekstrak variabel tersembunyi), **Ditanya:**, **Konsep dan Rumus Dasar:** (penjelasan teori naratif sebelum berhitung), dan **Langkah Penyelesaian:** (langkah bertahap yang terparameterisasi dengan `{{placeholder}}`).
     - `## Pembahasan: Trik Cepat`: Opsional, sertakan jika ada rumus praktis/trik cepat.
   * **Kalimat Penutup Wajib:** Setiap bagian pembahasan wajib diakhiri dengan `Jadi, jawaban yang benar adalah ${{answer}}$.` (atau teks hasil tebal).
   * **Tanpa Referensi Opsi:** Jangan menyebutkan huruf opsi (seperti "opsi D" atau "jawaban A") karena urutan opsi diacak di database.
7. Nama file Markdown output **sama dengan nama file input `.md`**. Contoh:
   * `phraser/01_q01.md` (atau `ori/01_q01.md`) → `solution/01_q01.md`
   * `phraser/01_q02.md` (atau `ori/01_q02.md`) → `solution/01_q02.md`
8. Simpan seluruh file Markdown hasil pembahasan ke dalam folder `solution/`.
9. Jika file tujuan sudah ada, timpa (overwrite) file tersebut.
10. Ulangi proses hingga seluruh soal selesai diproses menjadi file pembahasan di `solution/`.
11. Setelah semua soal selesai diproses, tampilkan ringkasan dalam bentuk file log format markdown yang disimpan di folder "Folder Input" dengan nama `summary.md`:
    * jumlah file Markdown yang diproses;
    * jumlah soal yang berhasil diproses menjadi file pembahasan (`solution/`);
    * jumlah file Markdown pembahasan yang dibuat;
    * daftar soal yang gagal diproses (jika ada) beserta penyebabnya.
```

### English Version

```bash
# Use skill `exam-solution-generator`

## Input Folder

`@013`

## Instructions

1. Use **Input Folder** as the working directory.
2. Read all files with `*.md` extension inside the `phraser/` subfolder (if paraphrasing was run) or the `ori/` subfolder in the Input Folder. Each file contains **one question**.
3. If a question has an image (e.g. JPG/PNG), search for an `.svg` file with the same name in that directory. If the `.svg` is found, inspect the image file to extract any given values or parameters embedded inside the diagram (such as angles, forces, initial velocities). If the `.svg` is missing, ignore/skip it.
4. Create a `solution/` folder inside the Input Folder if it does not exist yet.
5. Process each question using the **`exam-solution-generator` skill**.
6. For each question:
   * Generate one complete Markdown file containing YAML frontmatter and structured solution sections.
   * **YAML Frontmatter:** Must include metadata (`type`, `difficulty`, `tags`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`) and `variableFormulas` (at least 5 numerical variation sets and derived calculation formulas in plain `mathjs` syntax).
   * **Structured Solution Sections:**
     - `## Soal`: Question text with TeX formulas (`$...$` and `$$...$$`) and image references `![caption](file.png)`.
     - `## Opsi`: Option list using `- [x]` for correct options and `- [ ]` for incorrect options.
     - `## Alasan`: Reason content (for `statement_reasoning` type only).
     - `## Pembahasan: Cara Konseptual`: Mandatory section containing **Diketahui:** (explicitly extracting implicit variables), **Ditanya:**, **Konsep dan Rumus Dasar:** (narrative theory explanation before calculating), and **Langkah Penyelesaian:** (step-by-step calculation parameterized with `{{placeholder}}`).
     - `## Pembahasan: Trik Cepat`: Optional section, include if a shortcut formula exists.
   * **Mandatory Conclusion Sentence:** End every solution section with `Jadi, jawaban yang benar adalah ${{answer}}$.` (or bold text result).
   * **No Option Letter References:** Never reference option letters (such as "opsi D" or "jawaban A") as option order is randomized in the database.
7. The output Markdown filename **must match the input `.md` filename**. Example:
   * `phraser/01_q01.md` (or `ori/01_q01.md`) → `solution/01_q01.md`
   * `phraser/01_q02.md` (or `ori/01_q02.md`) → `solution/01_q02.md`
8. Save all enriched Markdown files into the `solution/` folder.
9. If the destination file already exists, overwrite it.
10. Repeat until all question files are processed into solution files in `solution/`.
11. After all questions are processed, generate a summary in the form of a markdown log file saved in the "Input Folder" named `summary.md`:
    * number of Markdown files processed;
    * number of questions successfully processed into solution files (`solution/`);
    * number of solution Markdown files created;
    * list of questions that failed to process (if any) along with the reasons.
```
