## Convert to BlockNote JSON (Tahap 2: Konversi JSON & Validasi)

### Versi Bahasa Indonesia

```bash
# Gunakan skill `exam-blocknote-converter`

## Folder Input

`@013`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file `.md` yang ada di dalam subfolder `solution/` pada Folder Input. Setiap file berisi **satu pembahasan soal terstruktur**.
3. Buat folder `exam/` di dalam Folder Input jika belum ada.
4. Konversi seluruh file pembahasan dari `solution/` menjadi format BlockNote JSON menggunakan **skill `exam-blocknote-converter`** atau skrip builder:
   ```bash
   python3 .agents/skills/exam-blocknote-converter/scripts/build_blocknote_json.py <Folder Input>/solution/ <Folder Input>/exam/
   ```
5. Setiap file JSON yang dihasilkan memuat seluruh atribut dan struktur BlockNote valid:
   * Metadata (`type`, `difficulty`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`, `tags`).
   * Struct `content` dan `solutions`: Semua teks berada di dalam objek block (`paragraph`, `bulletListItem`, `numberedListItem`, `equation`, `alert`).
   * **Opsi Jawaban:** Seluruh opsi dibungkus menggunakan block `paragraph` dengan inline node `latex`/`text`. Tidak boleh menggunakan block `equation` pada opsi.
   * **Gambar SVG Companion:** Jika file gambar dirujuk pada soal, cari file `.svg` dengan nama dasar yang sama. Jika ada, encode ke format Data URI (`data:image/svg+xml;utf8,...`) dan masukkan ke dalam block `image`.
   * **Sanitasi Aligned TeX:** Blok persamaan `\begin{aligned}` menggunakan variabel variabel tunggal pada baris pertama, `&=` pada setiap baris berikutnya, dan `\\[6pt] \implies` untuk pembalikan pecahan.
6. Nama file JSON output **sama dengan nama file input `.md`** (ganti ekstensi saja). Contoh:
   * `solution/01_q01.md` → `exam/01_q01.json`
   * `solution/01_q02.md` → `exam/01_q02.json`
7. Simpan seluruh file JSON ke dalam folder `exam/`.
8. Jika file tujuan sudah ada, timpa (overwrite) file tersebut.
9. Jalankan skrip validasi offline untuk memastikan seluruh file JSON yang dihasilkan valid secara skema, layout opsi, dan formula mathjs:
   ```bash
   python3 .agents/skills/exam-blocknote-converter/scripts/validate_questions.py <Folder Input>/exam/
   ```
10. Setelah semua soal selesai dikonversi dan divalidasi, tampilkan ringkasan berupa file log markdown yang disimpan di Folder Input dengan nama `summary.md`:
    * jumlah file `.md` di `solution/` yang diproses;
    * jumlah file JSON di `exam/` yang berhasil dibuat;
    * status hasil validasi dari `validate_questions.py`;
    * daftar file yang gagal diproses (jika ada) beserta alasannya.
```

### English Version

```bash
# Use skill `exam-blocknote-converter`

## Input Folder

`@013`

## Instructions

1. Use **Input Folder** as the working directory.
2. Read all `.md` files inside the `solution/` subfolder in the Input Folder. Each file contains **one structured question solution**.
3. Create an `exam/` folder inside the Input Folder if it does not exist yet.
4. Convert all solution files from `solution/` into BlockNote JSON format using the **`exam-blocknote-converter` skill** or the builder script:
   ```bash
   python3 .agents/skills/exam-blocknote-converter/scripts/build_blocknote_json.py <Input Folder>/solution/ <Input Folder>/exam/
   ```
5. Each output JSON file contains valid BlockNote structures:
   * Metadata (`type`, `difficulty`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`, `tags`).
   * Struct `content` and `solutions`: All text nodes must reside inside valid block objects (`paragraph`, `bulletListItem`, `numberedListItem`, `equation`, `alert`).
   * **Options Layout:** All options MUST use `paragraph` blocks containing inline `latex`/`text` nodes. Never use `equation` blocks for options.
   * **SVG Companion Embedding:** If an image is referenced, search for a companion `.svg` file with the same base name, encode it as Data URI (`data:image/svg+xml;utf8,...`), and insert as an `image` block.
   * **TeX Alignment Sanitization:** `\begin{aligned}` TeX blocks must use a single LHS variable on line 1, `&=` on subsequent lines, and `\\[6pt] \implies` for fraction inversion.
6. The output JSON filename **must match the input `.md` filename** (change extension only). Example:
   * `solution/01_q01.md` → `exam/01_q01.json`
   * `solution/01_q02.md` → `exam/01_q02.json`
7. Save all JSON files into the `exam/` folder.
8. If the destination file already exists, overwrite it.
9. Run the offline validator script to verify schema compliance, option layout, and mathjs formulas for all generated JSON files:
   ```bash
   python3 .agents/skills/exam-blocknote-converter/scripts/validate_questions.py <Input Folder>/exam/
   ```
10. Generate a summary in the form of a markdown log file saved in the Input Folder named `summary.md`:
    * number of `.md` files in `solution/` processed;
    * number of JSON files created in `exam/`;
    * validation status results from `validate_questions.py`;
    * list of files that failed to process (if any) along with reasons.
```
