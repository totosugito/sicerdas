## Convert to BlockNote JSON (Tahap 2: Konversi JSON & Validasi)

### Versi Bahasa Indonesia

```bash
# Gunakan skill `exam-blocknote-converter`

## Folder Input

`@013`

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca seluruh file `.md` yang ada di dalam subfolder `solution/` pada Folder Input. Setiap file berisi **satu pembahasan soal terstruktur**.
3. Buat folder `exam/` di dalam Folder Input jika belum ada.
4. Konversi seluruh file pembahasan dari `solution/` menjadi format BlockNote JSON menggunakan **skill `exam-blocknote-converter`** atau skrip builder:
   ```bash
   python3 .agents/skills/exam-blocknote-converter/scripts/build_blocknote_json.py <Folder Input>/solution/ <Folder Input>/exam/
   ```
5. Setiap file JSON yang dihasilkan memuat seluruh atribut dan struktur BlockNote valid:
   * Metadata (`type`, `difficulty`, `maxScore`, `scoringStrategy`, `requiredTier`, `isActive`, `tags`).
   * Struct `content` dan `solutions`: Semua teks berada di dalam objek block (`paragraph`, `bulletListItem`, `numberedListItem`, `equation`, `alert`).
   * **Opsi Jawaban:** Seluruh opsi dibungkus menggunakan block `paragraph` dengan inline node `latex`/`text`. Tidak boleh menggunakan block `equation` pada opsi.
   * **Gambar (PNG/JPG):** Jika file gambar dirujuk pada soal (contoh `.png` atau `.jpg`), pertahankan URL/path aslinya dan langsung masukkan ke dalam block `image`. Tidak perlu di-encode ke Base64.
   * **Sanitasi Aligned TeX:** Blok persamaan `\begin{aligned}` menggunakan variabel variabel tunggal pada baris pertama, `&=` pada setiap baris berikutnya, dan `\\[6pt] \implies` untuk pembalikan pecahan.
6. Nama file JSON output **sama dengan nama file input `.md`** (ganti ekstensi saja). Contoh:
   * `solution/01_q01.md` → `exam/01_q01.json`
   * `solution/01_q02.md` → `exam/01_q02.json`
7. Simpan seluruh file JSON ke dalam folder `exam/`.
8. Jika file tujuan sudah ada, timpa (overwrite) file tersebut.
9. Jalankan skrip validasi offline untuk memastikan seluruh file JSON yang dihasilkan valid secara skema, layout opsi, dan formula mathjs:
   ```bash
   python3 .agents/skills/exam-blocknote-converter/scripts/validate_questions.py <Folder Input>/exam/
   ```
10. Setelah semua soal selesai dikonversi dan divalidasi, tampilkan ringkasan berupa file log markdown yang disimpan di Folder Input dengan nama `summary.md`:
    * jumlah file `.md` di `solution/` yang diproses;
    * jumlah file JSON di `exam/` yang berhasil dibuat;
    * status hasil validasi dari `validate_questions.py`;
    * daftar file yang gagal diproses (jika ada) beserta alasannya.
```
