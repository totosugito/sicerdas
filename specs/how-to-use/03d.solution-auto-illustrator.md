## Generate Auto-Illustration for Solutions (Tahap Opsional: Penambahan Ilustrasi)

Langkah ini digunakan **setelah** Anda menjalankan generator pembahasan (03a atau 03c). Tujuannya adalah mendeteksi soal-soal teks yang akan jauh lebih mudah dipahami jika disertai ilustrasi visual (bangun datar, grafik koordinat, vektor gaya), membuat ilustrasinya dari nol dengan ECharts, dan menyisipkannya ke dalam pembahasan.

---

### Versi Bahasa Indonesia

#### Opsi 1: Single Agent

```bash
# Gunakan skill `exam-auto-illustrator`

## Folder Input

`@test` # Ganti sesuai dengan path folder kelompok soal

## Batasan Agent & Efisiensi Token
- **Eksekusi:** Gunakan HANYA 1 (single) main agent.
- **Efisiensi Skiping:** BACA file secara berurutan. Jika soal dirasa **TIDAK** membutuhkan ilustrasi geometris/matematis (misalnya soal teori hafalan, bahasa, atau soal yang sangat sederhana), **langsung lewati file tersebut** tanpa melakukan apa-apa untuk menghemat token.

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Baca file `.md` yang ada di dalam folder `solution/` secara berurutan.
3. Evaluasi bagian `## Soal` dan `## Pembahasan: Cara Konseptual`. Analisis apakah soal tersebut akan jauh lebih mudah dipahami oleh siswa jika disertai **ilustrasi visual/skema** (contoh: grafik fungsi Cartesian, poligon, segitiga, garis bilangan, diagram Venn, atau vektor fisis).
4. Jika **MEMBUTUHKAN** ilustrasi:
   * Bayangkan koordinat atau titik-titiknya secara geometris.
   * Buat struktur JSON ECharts dari nol yang merepresentasikan skema tersebut menggunakan aturan dari skill `exam-auto-illustrator` (termasuk aturan rasio isometrik 1:1 untuk geometri).
   * Simpan JSON tersebut di folder `imgs/` dengan format nama `imgs/<nama_soal>_auto.spec.json` (buat folder `imgs/` jika belum ada).
   * Jalankan script renderer lokal ECharts: `node .agents/skills/exam-chart-spec-processor/scripts/render_echarts.cjs imgs/<nama_soal>_auto.spec.json imgs/<nama_soal>_auto_draw.png 450 450` (sesuaikan ukuran canvas 450x450 atau 500x350 sesuai kecocokan).
   * Ubah file pembahasan tersebut:
     - Sisipkan sintaks Markdown gambar tepat di bawah *heading* `## Pembahasan: Cara Konseptual` (atau lokasi paling relevan di dalam pembahasan): `![Ilustrasi Pembahasan](imgs/<nama_soal>_auto_draw.png)`
   * **Ganti Nama File (Rename):** Simpan perubahan file pembahasan ke file baru bernama `solution/<nama_soal>-visual.md`. 
   * **Hapus** file solusi aslinya (`solution/<nama_soal>.md`) menggunakan command terminal (misal: `rm`) agar tidak terjadi duplikasi soal di sistem.
5. Ulangi proses ini hingga seluruh file di folder `solution/` selesai dievaluasi.
6. Buat file `auto_illustration_summary.md` di Folder Input yang berisi ringkasan jumlah soal yang diproses dan daftar file mana saja yang diubah menjadi berakhiran `-visual.md`.
```

### English Version

#### Option 1: Single Agent

```bash
# Use skill `exam-auto-illustrator`

## Input Folder

`@test` # Change according to the question group folder path

## Agent Constraints & Token Efficiency
- **Execution:** Use ONLY 1 (single) main agent.
- **Skipping Efficiency:** READ files sequentially. If a question **DOES NOT** require a geometric/mathematical illustration (e.g. pure theory, language questions, or very simple text), **immediately skip** the file doing nothing to save tokens.

## Instructions

1. Use **Input Folder** as the working directory.
2. Read the `.md` files inside the `solution/` folder sequentially.
3. Evaluate the `## Soal` and `## Pembahasan: Cara Konseptual` sections. Analyze whether the question would be significantly easier for a student to understand if accompanied by a **visual/schematic illustration** (e.g., Cartesian function graph, polygon, triangle, number line, Venn diagram, or physics vectors).
4. If it **REQUIRES** an illustration:
   * Mentally picture the geometric coordinates or data points.
   * Generate an ECharts JSON structure from scratch representing the scheme, adhering to the `exam-auto-illustrator` skill rules (including the 1:1 isometric ratio rule for pure geometry).
   * Save the JSON in the `imgs/` folder using the naming format `imgs/<question_name>_auto.spec.json` (create the `imgs/` folder if it doesn't exist).
   * Execute the local ECharts renderer script: `node .agents/skills/exam-chart-spec-processor/scripts/render_echarts.cjs imgs/<question_name>_auto.spec.json imgs/<question_name>_auto_draw.png 450 450` (adjust canvas size to 450x450 or 500x350 as appropriate).
   * Modify the solution file:
     - Insert the image Markdown syntax right below the `## Pembahasan: Cara Konseptual` heading (or the most relevant location in the explanation): `![Ilustrasi Pembahasan](imgs/<question_name>_auto_draw.png)`
   * **Rename File:** Save the modified solution into a new file named `solution/<question_name>-visual.md`.
   * **Delete** the original solution file (`solution/<question_name>.md`) using a terminal command (e.g., `rm`) to prevent duplicate questions in the system.
5. Repeat this process until all files in the `solution/` folder have been evaluated.
6. Create an `auto_illustration_summary.md` file in the Input Folder containing a summary of the number of processed questions and a list of the files that were converted to the `-visual.md` suffix.
```
