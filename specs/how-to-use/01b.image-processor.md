## Step 1b: Image Vision & SVG Processor (Ekstraksi Informasi Gambar & Rekreasi SVG/PNG untuk Siswa)

---

### Versi Bahasa Indonesia

#### Single Agent Execution

```bash
# Gunakan skill `exam-image-processor`

## Folder Input

`@test` # Atau tag folder spesifik seperti `@mma_snbt_2025` atau `@utbk`

## Klasifikasi 3 Tier Gambar & Ekstraksi UCDF Chart JSON

Setiap gambar cropped pada soal harus diklasifikasikan ke salah satu dari 3 tier berikut:

1. **Tier 1: Grafik / Chart Standard (UCDF Chart JSON + ECharts SSR PNG/SVG)**
   - *Jenis*: Diagram garis (`line`), grafik batang (`bar`), area chart (`area`), pie chart (`pie`), doughnut, radar chart.
   - *Deteksi Series*: Periksa apakah chart berupa **Single-Series** (1 kelompok data) atau **Multi-Series** (beberapa kelompok data/warna, misal *Modal vs Hasil*). Untuk Multi-Series, susun array `series` dengan objek individual untuk tiap kelompok warna dan tentukan opsi `stacked` (jika bertumpuk) serta `showLegend: true`.
   - *Tindakan*: 
     * Ekstrak struktur data ke format **Universal Chart Data Format (UCDF) JSON** di file `imgs/<nama_soal>.md`.
     * Render chart menggunakan **Apache ECharts SSR** (Node/Bun) menjadi file PNG high-DPI atau SVG.
     * Ubah referensi gambar di `.md` soal ke file hasil render.

2. **Tier 2: Diagram / Geometri / Vektor Sederhana (Rekreasi SVG Manual)**
   - *Jenis*: Bidang miring, katrol, vektor gerak parabola, sirkuit listrik sederhana, geometri.
   - *Tindakan*: Buat file deskripsi `imgs/<nama_soal>.md` **DAN** file SVG `imgs/<nama_soal>.svg` (kode SVG teks murni). Ubah referensi gambar di `.md` soal ke `.svg`.

3. **Tier 3: Gambar / Foto Komposisi Kompleks (Tetap Gunakan PNG/JPG)**
   - *Jenis*: Foto sel/organ biologi rumit, peta geografi berskala tinggi, foto dokumen bersejarah, karya seni bertekstur realistis.
   - *Tindakan*: Buat file deskripsi `imgs/<nama_soal>.md` **SAJA**. JANGAN konversi ke SVG/PNG baru. Tetap gunakan file PNG/JPG gambar asli.

## Ketentuan Rendering Chart via ECharts SSR (Khusus Tier 1)

- **Engine**: Apache ECharts via Node/Bun SSR (Server-Side Rendering).
- **Alasan**: Konsistensi 100% dengan chart interaktif di frontend web app SiCerdas (ECharts via `ReactECharts`). Visual identik, modern, dan estetis.
- **Proses**:
  1. Baca blok UCDF JSON dari `imgs/<nama_soal>.md`.
  2. Konversi UCDF JSON menjadi objek ECharts Option (termasuk smooth curve, gradient fill, clean gridlines, tipografi modern).
  3. Render menjadi file PNG (high-DPI @2x) atau SVG.
  4. Simpan ke `imgs/<nama_soal>.png` atau `imgs/<nama_soal>.svg`.

## Ketentuan Rekreasi SVG Manual (Khusus Tier 2)

- **Format Output**: Kode SVG murni, bukan gambar raster. Pastikan ukuran `viewBox` disesuaikan secukupnya (tight fit) agar tidak ada area putih (white space) kosong yang berlebihan di sekitar konten.
- **Bounding & Padding (Wajib)**: Gunakan elemen `<clipPath>` untuk kurva tak hingga. Hitung bounding box aktual dari seluruh elemen visual (termasuk label terluar), lalu atur `viewBox` agar memiliki **padding simetris yang persis sama dan seragam (contoh: persis 30px)** di keempat sisi (atas, bawah, kiri, kanan).
- **Penyampaian Informasi**: Gambar tidak harus 100% identik dengan aslinya; yang terpenting seluruh informasi soal (objek, panah, lintasan, label) tersampaikan dengan jelas.
- **Bentuk Dasar & Komentar**: Pakai bentuk dasar sederhana (`rect`, `line`, `circle`, `path`) dan beri komentar pendek di kode untuk tiap bagian.
- **Penanganan Label & Keterbacaan Teks (Wajib)**: Pertahankan angka seperti asli ATAU ganti dengan simbol ($v_0$, $\theta$). **WAJIB menambahkan atribut `stroke="rgba(255,255,255,0.9)" stroke-width="4" paint-order="stroke fill" stroke-linejoin="round"` pada tag `<text>`** agar tulisan memiliki batas (halo) putih semi-transparan. Hal ini mencegah teks tidak terbaca saat bertumpukan (overlap) dengan garis sumbu atau kurva grafik.
- **Ketepatan Matematis**: Pastikan titik koordinat, garis lurus, dan kurva parabola (`Q` Bezier) digambar dengan presisi berdasarkan skala piksel pada sumbu koordinat.
- **Gaya Visual**: Berwarna ceria ramah anak/siswa dengan kontras yang bersih dan jelas.
- **Garis & Vektor**: Garis putus-putus untuk lintasan/garis acuan; panah berkepala (`marker`) untuk vektor dan ukuran jarak.

## Instruksi

1. Gunakan **Folder Input** sebagai direktori kerja.
2. Pindai seluruh file `.md` di dalam subfolder `ori/` (misal `ori/001-020/*.md`).
3. Untuk setiap file soal yang memuat referensi gambar (contoh: `![image](imgs/img_in_box_...jpg)`):
   a. **Vision Inspection & Klasifikasi 3 Tier**:
      - Periksa dan analisa gambar mentah hasil crop OCR yang berada di folder `imgs/`.
      - Tentukan Klasifikasi Asset (**Tier 1: Chart UCDF**, **Tier 2: Diagram SVG**, atau **Tier 3: Gambar Kompleks**).
      - Jika Tier 1: Periksa apakah Single-Series atau Multi-Series, lalu susun objek UCDF JSON (`chartType`, `title`, `categories`, `series`, `options`).
      - Ekstrak seluruh informasi visual: jenis diagram, label sumbu, nilai koordinat/titik data, tabel angka, vektor gaya/kecepatan, sudut, dan hubungan variabel.
      - **Pendekatan Pedagogis Siswa**: Tulis penjelasan diagram dalam Bahasa Indonesia yang ramah siswa (SD/SMP/SMA/UTBK).
   b. **Buat File Deskripsi Gambar (`imgs/<nama_soal>.md`)** — *Wajib Untuk Semua Tier*:
      - Buat file `.md` pendamping di dalam folder `imgs/` dengan nama yang sama dengan file soal (contoh: `ori/001-020/imgs/019_q24.md`).
      - Memuat metadata tier, tipe series (Single vs Multi-Series), blok UCDF JSON (jika Tier 1), penjelasan ringkas siswa, tabel data terkstrak, dan parameter visual.
   c. **Buat Aset Visual** — *Khusus Tier 1 & Tier 2*:
      - **Tier 1 (Chart)**: Render chart menggunakan ECharts SSR menjadi `imgs/<nama_soal>.png` (high-DPI) atau `imgs/<nama_soal>.svg`.
      - **Tier 2 (Diagram)**: Tulis kode SVG teks murni menjadi `imgs/<nama_soal>.svg` (viewBox ± 500x300).
      - **Tier 3**: Lewati pembuatan aset visual baru.
   d. **Perbarui Referensi Gambar di Markdown Soal**:
      - Jika Tier 1: Ubah tag gambar ke file hasil render ECharts (`![chart](imgs/<nama_soal>.png)` atau `.svg`).
      - Jika Tier 2: Ubah tag gambar ke file SVG (`![diagram](imgs/<nama_soal>.svg)`).
      - Jika Tier 3: Pastikan tag gambar menunjuk ke file PNG/JPG asli di `imgs/`.
   e. **Koreksi & Sinkronisasi Teks Soal (Text-Vision Verification)**:
      - Bandingkan narasi/teks soal pada file `.md` dengan gambar hasil inspeksi vision.
      - Jika terdapat typo OCR, salah baca simbol (misal "garis 1" padahal gambar menunjukkan "Garis $l$"), atau ketidaksesuaian angka/variabel, perbarui teks soal di file `.md` agar konsisten 100% dengan gambar visual dan menggunakan format inline LaTeX yang rapi (misal `$l$`, `$v_0$`).
4. Soal yang TIDAK memuat gambar dapat dilewati (skip).
5. Buat laporan ringkas `imgs_summary.md` di Folder Input berisi daftar gambar yang diproses, klasifikasi tier, tipe series, blok UCDF JSON yang diekstrak, dan file yang dihasilkan.
```

### English Version

```bash
# Use skill `exam-image-processor`

## Input Folder

`@test` # Or tag a specific folder like `@mma_snbt_2025` or `@utbk`

## 3-Tier Image Classification & UCDF Chart JSON Extraction

Each cropped question image must be classified into one of three tiers:

1. **Tier 1: Standard Charts & Graphs (UCDF Chart JSON + ECharts SSR PNG/SVG)**
   - *Types*: Line charts (`line`), bar charts (`bar`), area charts (`area`), pie charts (`pie`), doughnut, radar charts.
   - *Series Detection*: Detect whether the chart is **Single-Series** or **Multi-Series** (multiple legend items/color groups, e.g. *Modal vs Hasil* or *Class A vs Class B*). Construct separate series objects for each dataset and set `stacked: boolean` and `showLegend: true`.
   - *Action*: 
     * Extract structured data into **Universal Chart Data Format (UCDF) JSON** inside `imgs/<question_name>.md`.
     * Render chart using **Apache ECharts SSR** (Node/Bun) to high-DPI PNG or SVG.
     * Update question markdown image reference to rendered file.

2. **Tier 2: Simple Diagrams / Geometry / Vectors (Manual SVG Redraw)**
   - *Types*: Inclined planes, pulleys, parabolic motion vectors, simple electrical circuits, geometry figures.
   - *Action*: Create companion description `imgs/<question_name>.md` **AND** hand-coded vector SVG `imgs/<question_name>.svg`. Update question `.md` to point to `.svg`.

3. **Tier 3: Complex Real-World Images & Photos (Keep Original PNG/JPG)**
   - *Types*: Detailed biology/anatomy photos, intricate geographic maps, historical documents, fine artwork/realistic textures.
   - *Action*: Create companion description `imgs/<question_name>.md` **ONLY**. Do NOT create SVG or PNG. Retain original PNG/JPG image asset.

## ECharts SSR Chart Rendering Guidelines (Tier 1 Only)

- **Engine**: Apache ECharts via Node/Bun SSR (Server-Side Rendering).
- **Rationale**: 100% visual consistency with SiCerdas web frontend interactive charts (ECharts via `ReactECharts`). Identical, modern, aesthetically premium output.
- **Process**:
  1. Read UCDF JSON block from `imgs/<question_name>.md`.
  2. Convert UCDF JSON to ECharts Option object (including smooth curves, gradient fills, clean gridlines, modern typography).
  3. Render to high-DPI PNG (@2x) or SVG.
  4. Save to `imgs/<question_name>.png` or `imgs/<question_name>.svg`.

## Manual SVG Creation Guidelines (Tier 2 Only)

- **Output Format**: Pure SVG text code, not raster images. Adjust the `viewBox` dimension to tightly fit the content, preventing excessive empty white space around the diagram.
- **Bounding & Padding (Mandatory)**: Use a `<clipPath>` for infinitely extending curves. Calculate the actual bounding box of all visual elements (including the outermost labels), and set the `viewBox` to have **strictly uniform, symmetrical padding (e.g. exactly 30px)** on all four sides (top, bottom, left, right).
- **Information Integrity**: The diagram does not need to be 100% identical; all question information (objects, arrows, trajectories, labels) must be clearly conveyed.
- **Primitives & Comments**: Use simple basic primitives (`rect`, `line`, `circle`, `path`) with short comments in the code for each section.
- **Labels & Text Readability (Mandatory)**: Preserve exact numerical labels OR swap numbers with symbols (e.g. $v_0$, $\theta$). **You MUST add `stroke="rgba(255,255,255,0.9)" stroke-width="4" paint-order="stroke fill" stroke-linejoin="round"` attributes to all `<text>` tags**. This adds a semi-transparent white halo behind the text, ensuring it remains highly readable even if it overlaps with axes or curves.
- **Mathematical Precision**: Ensure coordinate points, straight lines, and parabolic curves (using Bezier `Q` paths) are drawn precisely according to the pixel scale of the Cartesian axes.
- **Visual Style**: Student-friendly, bright color schemes with clear contrast.
- **Lines & Vectors**: Dashed lines for trajectories/reference lines; arrowhead markers for vectors and distance measurements.

## Instructions

1. Use **Input Folder** as the working directory.
2. Scan all `.md` files inside `ori/` subfolders (e.g. `ori/001-020/*.md`).
3. For each question file containing an image reference (e.g. `![image](imgs/img_in_box_...jpg)`):
   a. **Vision Inspection & 3-Tier Classification**:
      - Analyze the raw cropped OCR image in the `imgs/` directory.
      - Classify into **Tier 1 (UCDF Chart)**, **Tier 2 (SVG Diagram)**, or **Tier 3 (Complex Photo)**.
      - If Tier 1: Detect Single vs Multi-Series, then construct UCDF JSON object (`chartType`, `title`, `categories`, `series`, `options`).
      - Extract all visual elements: diagram type, axis labels, coordinates/data points, tables, vectors, angles, and variable relationships.
   b. **Create Companion Image Description File (`imgs/<question_name>.md`)** — *Mandatory for All Tiers*:
      - Save a `.md` description file in the `imgs/` folder named after the question file (e.g. `ori/001-020/imgs/019_q24.md`).
      - Includes tier metadata, series type, UCDF JSON block (if Tier 1), student-friendly explanation, extracted data tables, and visual parameters.
   c. **Create Visual Asset** — *Tier 1 & Tier 2 Only*:
      - **Tier 1 (Chart)**: Render via ECharts SSR to `imgs/<question_name>.png` (high-DPI) or `imgs/<question_name>.svg`.
      - **Tier 2 (Diagram)**: Write pure SVG text code to `imgs/<question_name>.svg` (viewBox ± 500x300).
      - **Tier 3**: Skip new visual asset creation.
   d. **Update Question Markdown Image Reference**:
      - If Tier 1: Update image link to ECharts rendered file (`![chart](imgs/<question_name>.png)` or `.svg`).
      - If Tier 2: Update image link to SVG (`![diagram](imgs/<question_name>.svg)`).
      - If Tier 3: Ensure image link references original PNG/JPG asset in `imgs/`.
   e. **Question Text & Vision Cross-Verification**:
      - Compare the question text in `.md` with visual elements in the crop image.
      - If there are OCR errors, misread line symbols (e.g. OCR read "line 1" when image shows "Line $l$"), or mismatched numbers/variables, update and fix the question `.md` text so it matches 100% with the image and uses inline LaTeX (e.g. `$l$`, `$v_0$`).
4. Questions WITHOUT images should be skipped.
5. Create a summary report `imgs_summary.md` listing processed images, tier classification, series type, UCDF JSON blocks extracted, and generated files.
```
