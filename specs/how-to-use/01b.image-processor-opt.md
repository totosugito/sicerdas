# Step 1b: Image Vision & SVG Processor

Dokumen ini berisi panduan penggunaan skill `exam-image-processor` untuk mengekstraksi konteks gambar & narasi soal, mengklasifikasikan aset visual, serta merekreasi diagram SVG / chart ECharts SSR.

---

## 1. Cara Eksekusi (Single Agent Prompt)

Salin dan jalankan template prompt berikut di chat untuk memproses seluruh gambar dalam folder target:

```bash
# Gunakan skill `exam-image-processor`

## Folder Input

`@test` # Ubah sesuai path folder grup soal, misal `@ori/001-020`

## Parameter Ukuran Canvas (Standard Canvas Presets)
- `default` (Landscape): `500x350` px — Diagram Geometri, Fisika, Flowchart, Kurva Fungsi 1-2 Kuadran.
- `square` (Isometrik 1:1): `450x450` px — Koordinat Kartesius 4 Kuadran, Lingkaran, Diagram Venn, Matriks.
- `wide` (Horizontal): `600x250` px — Garis Bilangan (Number Line), Rangkaian Listrik Horizontal, Timeline.
- `echarts` (Tier 1 SSR): `600x400` px — Grafik Batang, Garis, Pie/Doughnut Chart (render @2x DPI `1200x800`).

## Batasan Agent & Efisiensi Token
- **Eksekusi:** Gunakan HANYA 1 (single) main agent. Dilarang keras membuat/spawn sub-agent baru.
- **Pemrosesan:** Baca dan proses seluruh gambar & soal secara sekuensial (satu per satu) dalam satu agent loop untuk menghemat token dan mencegah duplikasi konteks.

## Instruksi
1. Buka folder kerja pada **Folder Input**.
2. Baca file narasi soal `.md` terlebih dahulu untuk memahami konteks matematika/fisika soal, sebelum memeriksa crop gambar asli di subfolder `imgs/`.
3. Klasifikasikan aset gambar ke dalam 3 Tier (Tier 1: UCDF Chart JSON + ECharts SSR, Tier 2: Diagram / Grafik Matematika Skala 1:1 SVG, Tier 3: PNG/JPG Asli).
4. Gunakan ukuran canvas standar yang sesuai jenis gambar (`500x350` landscape, `450x450` square isometrik, atau `600x250` wide) dengan root tag responsive `<svg viewBox="0 0 W H" width="100%" height="100%">`.
5. Khusus grafik matematika & koordinat Kartesius pada Tier 2, pastikan **skala aspek rasio sumbu X dan Y adalah 1:1 (isometrik)**.
6. Buat file deskripsi `imgs/<nama_soal>.md` untuk setiap gambar.
7. Untuk file SVG, jalankan skrip auto-fixer `python .agents/skills/exam-image-processor/scripts/svg_postprocess.py imgs/<nama_soal>.svg`.
8. Perbarui referensi tag gambar pada file soal `.md` di dalam subfolder `ori/` dengan path relatif yang benar (`../imgs/<nama_soal>.png` atau `../imgs/<nama_soal>.svg`).
9. Tampilkan ringkasan hasil pemrosesan di `imgs_summary.md`.
```

## 2. Ringkasan Prinsip Utama Pemrosesan

1. **Inspeksi Terpadu Teks Soal & Gambar (Joint Text + Vision Inspection)**:
   - **WAJIB membaca teks/narasi soal `.md` terlebih dahulu** untuk mendapatkan fakta matematika/fisika (misal: sifat geometri $AC = DC$, persamaan, sudut $p, q$, nilai variabel, atau satuan).
   - Analisis gambar cropped OCR (`imgs/img_in_box_...jpg`) bersama dengan konteks narasi soal.

2. **Klasifikasi Asset 3 Tier & Standar Dimensi**:
   - **Tier 1: Grafik / Chart Standard** $\rightarrow$ Ekstrak **UCDF Chart JSON** (Single/Multi-Series) ke `imgs/<nama_soal>.md` + Render via **Apache ECharts SSR** (`.png` / `.svg`) dengan dimensi render baku **`600 × 400` px** (@2x DPI `1200 × 800`).
   - **Tier 2: Diagram / Geometri Sederhana / Grafik Matematika** $\rightarrow$ Buat file deskripsi `imgs/<nama_soal>.md` + Rekreasi **SVG Manual** (`.svg`) menggunakan preset canvas standar (`500 × 350` px landscape, `450 × 450` px square isometrik, atau `600 × 250` px wide).
   - **Tier 3: Foto / Gambar Komposisi Kompleks** $\rightarrow$ Buat file deskripsi `imgs/<nama_soal>.md` **SAJA**, pertahankan file gambar PNG/JPG asli.

3. **Aturan Standar Visual & SVG (Tier 2)**:
   - **Preset Ukuran Canvas Baku & Responsive**:
     * **Landscape (Default)**: `viewBox="0 0 500 350"` (Diagram Geometri, Fisika, Bangun Ruang, Flowchart).
     * **Square (Isometrik 1:1)**: `viewBox="0 0 450 450"` (Koordinat Kartesius 4 Kuadran, Lingkaran, Transformasi Geometri).
     * **Wide (Horizontal)**: `viewBox="0 0 650 250"` (Garis Bilangan, Rangkaian Listrik Horizontal, Garis Waktu).
     * **Format Root Tag SVG**: Wajib menyertakan `width="100%" height="100%"` agar scalable dan responsive di aplikasi web/mobile.
   - **Skala 1:1 Sumbu X dan Y pada Grafik Matematika (Math Chart Aspect Ratio 1:1)**: Untuk seluruh grafik fungsi matematika, koordinat Kartesius, kurva parabola/trigonometri/polinomial, dan geometri bidang, **WAJIB menggunakan skala isometrik 1:1 antara sumbu X dan sumbu Y** (1 unit panjang pada X = 1 unit panjang pada Y, misal: 1 unit = 40px). Hal ini mutlak agar kemiringan garis/gradien ($m = \Delta y / \Delta x$), sudut tegak lurus $90^\circ$, sudut $45^\circ$, dan bentuk geometri (lingkaran tidak lonjong/elips) akurat dan presisi 100%.
   - **Styling Terpusat `<defs><style>`**: Seluruh atribut gaya (`stroke`, `fill`, `font-family`, `halo stroke`) WAJIB dikelompokkan ke dalam class CSS terpusat (`.line-main`, `.line-sec`, `.point`, `.text-label`, `.text-var`, `.text-highlight`) di `<defs><style>`. JANGAN mengulang style inline pada tag elemen SVG.
   - **Padding Seragam**: `viewBox` wajib memiliki **padding simetris persis 20px** di keempat sisi (atas, bawah, kiri, kanan).
   - **Skema Warna Baku**: Gunakan `#1e293b` (Charcoal / Hitam Elegan) sebagai warna standar baku untuk seluruh garis utama, kotak flowchart, dan geometri (`.line-main`). Gunakan `#64748b` untuk sumbu/grid (`.line-sec`), dan `#dc2626` (Merah Ceria) **HANYA untuk item target yang ditanyakan dalam soal (Interest Item)** (`.text-highlight` / `.line-highlight`).
   - **Dilarang Komentar Kalkulasi**: JANGAN menuliskan komentar rumus, trigonometri, atau draf perhitungan koordinat di dalam kode SVG.
   - **Halo Stroke Teks di CSS Class**: Properti halo teks (`stroke: rgba(255,255,255,0.95); stroke-width: 4px; paint-order: stroke fill; stroke-linejoin: round;`) WAJIB dimasukkan langsung di dalam definisi class CSS (`.text-label`, `.text-var`) pada `<defs><style>`. JANGAN menuliskan atribut `stroke="..."` secara inline pada tag `<text>`.

4. **File Deskripsi Komprehensif (`imgs/<nama_soal>.md`)**:
   - Selalu buat file `.md` pendamping di folder `imgs/` sebagai **Single Source of Truth** yang menyimpan seluruh konteks narasi soal, metadata tier, UCDF JSON (jika Tier 1), penjelasan ringkas siswa, dan tabel data terkstrak.

5. **Pengecekan Akhir & Otomasi Padding Simetris 20px**:
   - **Post-Processing Auto-Fixer**: Setelah file SVG disimpan, jalankan `python .agents/skills/exam-image-processor/scripts/svg_postprocess.py imgs/<nama_soal>.svg`. Skrip ini secara otomatis:
     1. Memperhitungkan batas huruf bawah (font descender untuk huruf $y, g, p, q$) agar teks di bagian bawah **TIDAK pernah terpotong**.
     2. Menyesuaikan koordinat `<rect>` latar belakang putih agar menutupi seluruh canvas `viewBox`.
     3. Mengkoreksi `viewBox` agar memiliki **padding simetris yang persis 20px** di keempat sisi (atas, bawah, kiri, kanan).
